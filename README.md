# BuildFlow 🚀

BuildFlow is a construction ERP & SaaS platform designed to control
project cost, materials, labour, and client communication in real time.

## Tech Stack
- Backend: Node.js (Express/NestJS)
- Mobile App: Flutter
- Database: PostgreSQL
- AI (Phase 2): Python

## Repository Structure
/backend     → API services  
/mobile-app  → Flutter application  
/ai-service  → AI microservices  
/docs        → Product & API documentation
